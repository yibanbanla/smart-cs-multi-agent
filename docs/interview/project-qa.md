# 项目深度问答

> 结合当前 Python 实现整理的面试追问示例。

---

## Q1：Supervisor 编排和 if-else 路由有什么区别？

**回答要点**：

- if-else 只能处理简单分发
- Supervisor + StateGraph 能表达条件分支、汇聚节点、检查点恢复和统一兜底
- 在客服场景里，合规审查是固定流程节点，用图编排更稳

## Q2：为什么要做分层记忆？

**回答要点**：

- 工作记忆解决当前请求内的状态传递
- 短期记忆解决多轮对话上下文衔接
- 长期记忆解决知识库和历史信息检索

如果只靠 prompt 堆全部历史，成本高、效果也容易乱。

## Q3：RAG 流程里为什么要先检索再重排序？

**回答要点**：

- Top-K 检索保证召回
- 重排序提高精度
- 最后只把最相关文档放进上下文，控制 Token

## Q4：MCP 协议层的价值是什么？

**回答要点**：

- 工具描述标准化
- 工具发现和调用方式统一
- 新增工具时对 Agent 主逻辑影响更小

## Q5：为什么要接 OpenTelemetry？

**回答要点**：

- 一个请求会经过多个 Agent 和工具
- 没有链路追踪时，很难定位到底慢在哪一段
- 追踪可以帮助看耗时、错误率和工具调用情况

## Q6：如果某个 Agent 超时了怎么办？

**回答要点**：

- 设置超时控制
- Supervisor 做降级处理
- 必要时转人工或创建工单

## Q7：这个项目的难点在哪？

**回答要点**：

- 多 Agent 状态协调
- 合规审查必须稳定接入主流程
- RAG 结果既要准，又要控制上下文成本
- 工具调用需要统一协议和日志
